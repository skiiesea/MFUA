# Telegram-бот «Задания» с реферальной системой и балансом

Аналог RubUp: пользователи выполняют задания (подписка на каналы), получают деньги
на внутренний баланс, приглашают друзей и подают заявки на вывод средств.
Администратор управляет заданиями и заявками прямо в Telegram.

## Возможности

- `/start` и реферальные ссылки вида `https://t.me/<bot>?start=ref_<id>`;
- профиль: баланс, всего заработано, число приглашённых, реферальная ссылка;
- список активных заданий с пагинацией;
- проверка подписки на канал через `getChatMember` с предварительной проверкой
  прав бота в канале;
- начисление награды ровно один раз за задание (уникальный индекс + транзакция);
- заявка на вывод: деньги списываются сразу, при отклонении — возвращаются;
- админ-панель: добавление/снятие заданий, заявки на вывод, рассылка, статистика.

## Стек

- Python 3.10+
- [aiogram 3.x](https://docs.aiogram.dev/)
- SQLite через `aiosqlite`
- `python-dotenv`

## Быстрый старт

```bash
cd telegram-bot

python -m venv .venv
# Windows:
.venv\Scripts\activate
# Linux/macOS:
source .venv/bin/activate

pip install -r requirements.txt

copy .env.example .env      # Windows
# cp .env.example .env      # Linux/macOS

# заполните .env и запустите
python main.py
```

> Если `python -m venv` падает с ошибкой `ensurepip` (например, в Python 3.15 без
> встроенного ensurepip), создайте окружение через
> [uv](https://docs.astral.sh/uv/):
>
> ```bash
> uv venv --python 3.14 .venv
> uv pip install --python .venv\Scripts\python.exe -r requirements.txt
> .venv\Scripts\python main.py
> ```

## Переменные окружения

| Переменная        | Обязательна | Описание                                              |
|-------------------|-------------|-------------------------------------------------------|
| `BOT_TOKEN`       | да          | токен от [@BotFather](https://t.me/BotFather)         |
| `ADMIN_IDS`       | да          | ID администраторов через запятую                      |
| `REFERRAL_REWARD` | да          | бонус пригласившему за первое задание друга, ₽ (`0` — выключить) |
| `MIN_WITHDRAW`    | да          | минимальная сумма вывода, ₽                           |
| `DB_PATH`         | нет         | путь к базе, по умолчанию `data/bot.db`               |

Суммы в `.env` указываются в рублях, поддерживаются копейки: `MIN_WITHDRAW=100.50`.
Внутри бот хранит деньги в копейках (`INTEGER`), чтобы избежать ошибок округления.

## Как это работает

### Задания

1. Админ добавляет задание: название, описание, канал (`@username` или `-100...`),
   награду. Бот сразу проверяет, что это канал и что он сам в нём администратор.
2. Пользователь открывает «📋 Задания», переходит в канал по кнопке и нажимает
   «✅ Проверить подписку».
3. Бот проверяет подписку и начисляет награду в одной транзакции.

### Рефералы

Ссылка `/start=ref_<user_id>` фиксирует пригласившего только при регистрации нового
пользователя. Бонус начисляется пригласившему **после первого выполненного задания**
приглашённым — это отсекает накрутку пустыми аккаунтами. Повторной выплаты нет:
флаг `referral_bonus_paid` хранится в БД.

### Вывод средств

1. Пользователь вводит сумму (FSM), бот проверяет минимум и баланс.
2. Сумма **сразу списывается** с баланса и создаётся заявка `pending`.
3. Админ одобряет (`approved`) или отклоняет (`rejected`) заявку.
4. При отклонении средства возвращаются на баланс в той же транзакции.

Бот не переводит деньги автоматически — выплата выполняется вручную после одобрения.

## Админ-панель

Доступна администраторам из `ADMIN_IDS` по команде `/admin` или кнопке
«⚙️ Админ-панель».

- **➕ Добавить задание** — пошаговый диалог, канал валидируется сразу;
- **🗂 Активные задания** — снять задание с публикации (мягкое удаление:
  история выполнений сохраняется, повторно получить награду нельзя);
- **💸 Заявки на вывод** — карточка заявки с подтверждением выплаты или возвратом;
- **📢 Рассылка** — копирует любое сообщение всем пользователям с учётом лимитов
  Telegram (`copy_message`, пауза между отправками);
- **📊 Статистика** — пользователи, задания, балансы, заявки.

## Требования к каналу

Бот должен быть **администратором канала**. `getChatMember` для проверки подписки
доступен только администраторам; перед начислением бот отдельно проверяет свой
статус в канале и не засчитывает задание, если прав нет.

## Защита от накруток и багов

- `UNIQUE (user_id, task_id)` в `user_tasks` — повторное выполнение невозможно даже
  при одновременных запросах; вставка идёт через `INSERT OR IGNORE` + проверка
  `rowcount`, начисление — в той же транзакции `BEGIN IMMEDIATE`;
- все операции с балансом сериализованы блокировкой и выполняются в транзакциях;
- `CHECK (balance >= 0)` и `UPDATE ... WHERE balance >= ?` не дают уйти в минус;
- списание при создании заявки и возврат только при отклонении;
- реферальный бонус — один раз на приглашённого, после его первого задания;
- проверка прав бота перед засчитыванием подписки;
- суммы в копейках (`INTEGER`) — без ошибок плавающей точки;
- HTML-экранирование имён пользователей и названий заданий.

## Схема базы данных

```
users
  user_id INTEGER PK
  username, full_name
  referrer_id INTEGER -> users.user_id
  balance, total_earned INTEGER (копейки)
  referral_bonus_paid INTEGER (0/1)
  created_at TEXT

tasks
  id INTEGER PK
  title, description
  channel_id, channel_link
  reward INTEGER (копейки)
  is_active INTEGER (1/0)
  created_at TEXT

user_tasks
  id INTEGER PK
  user_id -> users, task_id -> tasks
  status ('pending'/'completed'), reward_paid
  created_at, completed_at
  UNIQUE (user_id, task_id)

withdrawals
  id INTEGER PK
  user_id -> users
  amount INTEGER (копейки)
  status ('pending'/'approved'/'rejected')
  admin_id, created_at, processed_at
```

## Продакшн-заметки

- запускайте **один** экземпляр бота: SQLite и `MemoryStorage` не рассчитаны на
  несколько процессов;
- FSM хранится в памяти: после перезапуска незавершённые диалоги сбрасываются;
- база создаётся автоматически в `data/bot.db` (каталог игнорируется git);
- для автозапуска используйте systemd (Linux) или Планировщик задач (Windows):

```ini
[Unit]
Description=Telegram tasks bot
After=network.target

[Service]
WorkingDirectory=/opt/telegram-bot
ExecStart=/opt/telegram-bot/.venv/bin/python main.py
Restart=always

[Install]
WantedBy=multi-user.target
```

## Ограничения

- выплаты не автоматизированы (нет интеграции с платёжными системами);
- проверка подписки выполняется только в момент нажатия кнопки — повторная
  подписка/отписка после начисления на баланс не влияет;
- для приватных каналов нужна ссылка-приглашение, которую указывает админ.
