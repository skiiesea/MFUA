# Лабораторная работа №1 — вариант 1

Проект сделан на C++ в простом стиле: `main.cpp`, `functions.h` и `plain_methods.h`.

## Функции варианта

| № | Функция | Отрезок |
|---|---|---|
| 9 | `cos(x)` | `[pi/2; 3pi/2]` |
| 14 | `x^5 - 5x^3` | `[-4; 0]` |
| 16 | `x^6 - 5x^2` | `[-1; 1]` |
| 19 | `x^3 + 9x` | `[-1; 1]` |
| 27 | `6x^2 - 12x` | `[-4; 0]` |
| 50 | `(3x^4 - 12x) * cos(x)` | `[-2; 0]` |

## Что находится в папке

- `main.cpp` — запуск всех функций и методов, вывод результатов и создание `iterations.csv`.
- `functions.h` — шесть функций варианта 1.
- `plain_methods.h` — равномерный перебор, локализация, дихотомия, золотое сечение и Фибоначчи.
- `graphs/` — шесть готовых графиков зависимости числа итераций от ширины отрезка.
- `iterations.csv` — данные для графиков.
- `make_graphs.py` — скрипт для повторного построения графиков.

## Сборка в Visual Studio

1. Создай пустой проект C++ или открой папку проекта.
2. Добавь `main.cpp`, `functions.h` и `plain_methods.h`.
3. В свойствах проекта выбери стандарт языка **ISO C++17**.
4. Запусти сборку: **Сборка → Собрать решение**.
5. Запусти программу: **Отладка → Запуск без отладки** (`Ctrl + F5`).

## Сборка через g++

Нужен компилятор с поддержкой C++17 или новее:

```bash
g++ -std=c++17 -O2 main.cpp -o lab1
./lab1
```

В Windows:

```powershell
g++ -std=c++17 -O2 main.cpp -o lab1.exe
.\lab1.exe
```

После запуска в рабочей папке появится `iterations.csv`.

Чтобы заново построить PNG-графики по CSV, установи Python и matplotlib (`python -m pip install matplotlib`), затем выполни:

```bash
python make_graphs.py
```

## Точность

- Для поиска экстремума в основной части программы используется `EPS = 1e-6`.
- Для построения графиков используется `GRAPH_EPS = 1e-2`, чтобы равномерный перебор не создавал слишком большой объём вычислений.

## Важное замечание по функциям

Не все заданные отрезки являются унимодальными для поиска минимума. Например, у функций №14 и №16 на исходном отрезке есть несколько участков поведения, а у №16 два равных минимума на концах. Поэтому для методов, рассчитанных на унимодальную функцию, результаты на полном исходном отрезке нужно оценивать с учётом этого условия. В коде дополнительно сравниваются найденная точка и исходные концы отрезка.

Для графиков ширина интервала меняется на участках, выбранных около минимума так, чтобы не выходить за заметный участок монотонного поведения. Для функции №9 интервалы строятся симметрично относительно `pi`.
