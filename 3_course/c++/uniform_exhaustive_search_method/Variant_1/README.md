# Лабораторная работа №1 — вариант 1

Проект сделан на C++ в простом стиле: `main.cpp`, `functions.h` и `plain_methods.h`.

## Функции варианта

| № | Функция | Отрезок |
|---|---|---|
| 9 | `cos(x)` | [pi/2; 3pi/2] |
| 14 | `x^5 - 5x^3` | [-4; 0] |
| 16 | `x^6 - 5x^2` | [-1; 1] |
| 19 | `x^3 + 9x` | [-1; 1] |
| 27 | `6x^2 - 12x` | [-4; 0] |
| 50 | `(3x^4 - 12x) * cos(x)` | [-2; 0] |

## Файлы

- `main.cpp` — запуск методов, вывод результатов и создание `iterations.csv`.
- `functions.h` — шесть функций варианта 1.
- `plain_methods.h` — пять методов оптимизации.
- `iterations.csv` — данные для построения графиков в Excel.

## Сборка в Visual Studio

1. Создай консольный проект C++.
2. Добавь в него `main.cpp`, `functions.h` и `plain_methods.h`.
3. Выбери стандарт языка C++17.
4. Собери проект и запусти без отладки (Ctrl + F5).

## Сборка через g++

Открой терминал в папке проекта:

```bash
g++ -std=c++17 -O2 main.cpp -o lab1
./lab1
```

В Windows:

```powershell
g++ -std=c++17 -O2 main.cpp -o lab1.exe
.\lab1.exe
```

После запуска программа создаст файл `iterations.csv`.

## Построение графиков в Excel

1. Запусти программу, чтобы обновить `iterations.csv`.
2. Открой CSV в Excel (если мастер импорта появится, выбери разделитель «запятая»).
3. Для каждой функции отфильтруй столбец `function` по нужному номеру.
4. Сделай сводную таблицу: строки — `h`, столбцы — `method`, значения — `iterations`.
5. Выдели сводную таблицу и выбери **Вставка → Диаграммы → График**.
6. Повтори для функций №9, 14, 16, 19, 27 и 50. На каждом графике должны быть пять линий — по одной на метод.

## Точность

- Для поиска экстремума: `EPS = 1e-6`.
- Для подсчёта итераций в графиках: `GRAPH_EPS = 1e-2`.

## Примечание

Методы дихотомии, золотого сечения и Фибоначчи предполагают унимодальность функции на рассматриваемом интервале. Некоторые функции варианта имеют минимум на границе или несколько одинаковых минимумов, поэтому результаты нужно оценивать с учётом этого условия.
