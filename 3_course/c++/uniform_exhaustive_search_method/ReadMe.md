# Лабораторная работа №1. Одномерная оптимизация функций одной переменной

## Цель работы

Научиться применять численные методы одномерной оптимизации для нахождения экстремума (минимума или максимума) функции одной переменной на заданном отрезке с заданной точностью. Сравнить эффективность различных методов: равномерного перебора, локализации экстремума, дихотомии, золотого сечения и Фибоначчи.

---

## Теоретические сведения

В данной работе используются следующие методы одномерной оптимизации:

- **Метод равномерного перебора** — простой, но ресурсоёмкий метод, при котором отрезок разбивается на равные части, и функция вычисляется в каждой точке.
- **Метод локализации экстремума** — использует последовательное сужение интервала, содержащего экстремум, на основе сравнения значений функции в двух точках.
- **Метод дихотомии** — делит интервал пополам, выбирая подинтервал, где функция принимает меньшее значение (для минимизации).
- **Метод золотого сечения** — более эффективный, чем дихотомия, за счёт постоянного отношения длин подинтервалов ($\varphi = \frac{\sqrt{5}-1}{2} \approx 0.618$).
- **Метод Фибоначчи** — оптимален по количеству вычислений функции для заданного числа итераций; использует числа Фибоначчи для выбора точек.

> **Примечание**: Все методы предполагают, что функция унимодальна на отрезке $[a, b]$ — имеет один экстремум.
