# NORTH BANK — локальный демонстрационный банк

Самостоятельный учебный прототип банковского интерфейса. Это не банк, не финансовая организация и не платёжная система. Балансы, карты, клиенты и операции вымышлены; реальные платежи и переводы не поддерживаются.

## Запуск на Windows / PowerShell

Требуется Node.js 20 или новее.

```powershell
cd E:\git\MFUA\north-bank
npm install
npm run dev
```

Откройте в браузере: http://localhost:5174

Одна команда запускает два локальных процесса:
- Vite frontend: порт 5174
- Demo API: только 127.0.0.1:4175

Остановить оба процесса: Ctrl+C.

## Что уже реализовано

- Главная панель с общим балансом, счетами, доходами, расходами и последними операциями.
- Виртуальные счета и визуальные макеты карт без платёжных реквизитов.
- Тестовые переводы, платежи и пополнение вымышленного баланса.
- История операций и поиск.
- Профиль, переключение темы и сброс демонстрационных данных.
- Локальный API с проверкой суммы, существования счёта и доступного демо-баланса.
- Данные демо-аккаунтов сохраняются в `server/data/demo-state.json` и переживают перезапуск приложения.

## Границы безопасности

- Сервер API привязан к loopback-интерфейсу `127.0.0.1` и предназначен только для локального тестирования.
- Не вводите настоящие пароли, банковские реквизиты, данные карт или персональные финансовые сведения.
- Не подключайте реальные банковские API и не используйте проект для хранения настоящих денег.
- Все действия изменяют только локальную фиктивную базу проекта.
