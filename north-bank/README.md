# NORTH BANK — локальный демонстрационный банк

Самостоятельный учебный банковский симулятор с React, TypeScript, Vite и локальным Node.js API. Это не банк, не финансовая организация и не платёжная система. Все клиенты, счета, карты, балансы и операции вымышлены.

## Запуск на Windows / PowerShell

Требуется Node.js 20 или новее.

```powershell
cd E:\git\MFUA\north-bank
npm install
npm run dev
```

Откройте http://localhost:5174

Одна команда запускает два процесса:
- Frontend (Vite): http://localhost:5174
- Demo API: http://127.0.0.1:4175

Остановить оба процесса: Ctrl+C.

## Разделы приложения

- **Главная:** общий виртуальный баланс, быстрые действия, счета и последние операции.
- **Счета:** создание демо-счетов, переименование, просмотр балансов.
- **Карты:** создание макетов, привязка к демо-счёту и переключение статуса активна/заморожена.
- **Платежи:** тестовые платежи, внешние демо-переводы, переводы между собственными счетами и пополнения.
- **История:** поиск и фильтрация поступлений/списаний.
- **Аналитика:** суммы поступлений/списаний и расходы по категориям.
- **Накопления:** создание целей и внесение виртуальных взносов со счёта.
- **Уведомления:** локальная лента и отметка прочтения.
- **Профиль:** редактирование отображаемого имени, тема, настройки уведомлений и сброс демо-среды.
- **Поддержка:** создание локальных обращений без реального оператора.
- **Демо-панель:** агрегаты и журнал событий локального прототипа.

## Структура кода

- `src/features/` — независимые страницы и функциональные модули.
- `src/components/` — общие UI-компоненты.
- `src/api.ts`, `src/types.ts`, `src/format.ts` — клиент API, типы и форматирование.
- `server/` — локальный API и интеграционные тесты.

## Хранение и API

- JSON-файл базы: `server/data/demo-state.json` (создаётся автоматически).
- Все изменяющие запросы сериализуются очередью, чтобы локальные операции не перезаписывали друг друга.
- Сервер API слушает только `127.0.0.1`.
- Vite проксирует запросы `/api` на локальный API.
- Сброс демо-данных возвращает исходные счета, карты, цели и операции.

## Проверки

```powershell

npm run build
```

GitHub Actions выполняет сборку, интеграционные тесты API и проверку синтаксиса Node.js при изменениях проекта.

## Границы безопасности

- Демо-панель не является защищённой административной системой и не имеет реальной авторизации.
- Не вводите настоящие пароли, банковские реквизиты, данные карт или персональные финансовые сведения.
- Здесь нет реальных платежей, банковских API, выпуска карт или подключения к финансовым организациям.
- Все изменения относятся только к локальным вымышленным данным.
