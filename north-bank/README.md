# North — личный банк (демо)

Изолированный фронтенд-прототип банковского приложения. Не является банком и не подключён к платёжным системам.

## Запуск на Windows / PowerShell

```powershell
cd E:\git\MFUA\north-bank
npm install
npm run dev
```

Откройте http://localhost:5174

## Возможности прототипа
- Главная с демонстрационным балансом и графиком расходов.
- Виртуальные счета и карты.
- Переводы между своими демо-счетами и платежи с тестовым подтверждением.
- История операций, поиск и фильтры.
- Профиль и настройки интерфейса.
- Данные сохраняются только в localStorage этого браузера; кнопка сброса возвращает демо-данные.

Все суммы, карты, получатели и операции вымышлены. Не вводите реальные банковские реквизиты, пароли или персональные финансовые данные. Никакие операции не отправляются в банк и не перемещают реальные деньги.
